# site-member-pants

The homepage of pants_the_person: a 486, DOS games, MIDI files and too many animated GIFs.

This is a fictional 1990s-style homepage built with [Astro](https://astro.build): tiled
backgrounds, a scrolling marquee, a hit counter, an under-construction banner, a
guestbook and a small blog. All artwork is CSS, SVG or ASCII made for this repo.

## Development

```sh
npm install
npm run dev
```

## Build

```sh
npm run build
npm run preview
```

## Deployment

Pushes to `main` are built and deployed to GitHub Pages by
`.github/workflows/deploy.yml`.

Live site: https://pants-the-person.github.io/site-member-pants/
